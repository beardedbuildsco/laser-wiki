# Engraving a plaque from start to finish

Plaques are a Bearded Builds staple: awards, leadership recognition, shop dedications, and gifts. This walkthrough covers a typical flat plaque — wood, laminate, acrylic, or slate — from art intake to packed product.

Exact power numbers live in *your* Material Library after a [test grid](../materials/starter-settings.md). The process below is what keeps orders predictable when names and titles change on every piece.

## 1. Clarify the order

Before you open LightBurn, lock down:

- Finished size and blank material
- Exact text (names, titles, dates) — get it in writing
- Logo files (prefer vector) and any brand color constraints (engraving is often monochrome contrast)
- Quantity, deadline, and proof approval rules
- Whether the plaque ships framed, with standoffs, or bare

Typos that survive proofing become expensive keepsakes. Send a digital proof and wait for written approval on multi-name sets.

## 2. Prep the blank

- Inspect for defects, warp, and coating issues
- Wipe dust; avoid oily cleaners that leave residue
- Mask if you use transfer mask for cleaner edges on wood/acrylic (optional by material)
- Note thickness for focus
- For wood, check grain direction if the design has long horizontal rules — tear-out and char read differently with the grain

Skip mystery plastics — see [what you can laser](../materials/what-you-can-laser.md).

## 3. Build the file

1. Set the LightBurn page to the plaque size (or use Absolute Coordinates carefully).
2. Import logo; size it with margin from the edges (crowded edges look accidental).
3. Set type — readable fonts beat tiny script at plaque viewing distance.
4. Align centers or use a consistent left hierarchy for multi-line titles.
5. Put engrave fills on one layer; optional score lines on another; cut outlines only if you are cutting the blank shape yourself.
6. Convert critical text to paths once fonts are final if the file will move between PCs.
7. Keep a “safe margin” from the physical edge so framing error or slight blank undersize does not clip text.

## 4. Proof on screen, then on scrap

- Zoom out: does the layout feel balanced?
- Spellcheck names against the order email — watch Jr./Sr., middle initials, and accented characters
- Run a scrap test for contrast on the *same* material lot
- Adjust interval/power for darkness without digging craters
- If the client cares about depth (finger-feel engraving), confirm that on scrap, not on the paid blank

## 5. Fixture and focus

- Square the plaque to the bed axes (painter’s tape L-jigs work)
- Focus to the top surface ([focus and alignment](../machines/focus-and-alignment.md))
- Frame the job; confirm margins visually
- For repeat orders, screw down a simple corner jig so every blank lands in the same origin

## 6. Run the job

- Exhaust on; stay present ([ventilation and safety](../machines/ventilation-and-safety.md))
- Engrave first on multi-operation jobs when order matters for your process
- If flame appears, stop, extinguish safely, reassess settings
- For long fills, listen for changes in sound that can hint at focus shift or debris on the lens

## 7. Finish and QC

- Remove mask if used; brush or light wipe residue
- Optional finish: oil, clear coat, or polish — match the product line and let cure times finish before packing
- QC checklist: spelling, logo integrity, chips, contrast, back hardware alignment
- Photograph for your records / customer message
- If one name in a batch fails QC, remake it before the whole set ships — partial deliveries create support headaches

## 8. Pack like it matters

Awards get scrutinized. Corner protectors, fit-to-box packing, and a thank-you note reduce damage claims and build brand. Include care instructions when finishes are fresh.

## Production tips for name lists

When every plaque has a different name (common for leadership sets):

- Keep a master template; drive names from a CSV / merge workflow if you use one
- Batch by material thickness so focus stays consistent
- Queue files with clear filenames: `2026-Q4_Leader_Jane-Doe.lbrn2`
- Price setup time honestly — variable data is not “the same as one plaque times N” ([pricing laser work](../business/pricing-laser-work.md))
